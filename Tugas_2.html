LAPORAN TUGAS PERTEMUAN 2: DATA MINING#

Integrasi Database Cloud (Aiven), Analisis Statistik (KNIME), dan Web Deployment#

Latar Belakang#

Dalam proses data mining (penambangan data), mengolah data mentah menjadi informasi yang berharga membutuhkan tahapan awal yang sangat krusial, yaitu Data Understanding atau pemahaman data. Sebelum menerapkan algoritma atau pemodelan yang kompleks, seorang analis harus terlebih dahulu memahami jenis data, skala pengukuran, serta karakteristik dasar dari himpunan data (dataset) yang digunakan.
Pembuatan ringkasan statistik dasar memegang peranan penting dalam tahapan ini. Melalui deskripsi statistik, kita dapat memahami karakteristik fundamental data, seperti mengukur tendensi sentral (central tendency) yang meliputi mean dan median untuk mengetahui letak pusat data. Selain itu, statistik dasar juga membantu kita mengukur tingkat penyebaran data (data dispersion) melalui perhitungan varians dan standar deviasi. Pemahaman yang kuat terhadap metrik-metrik ini sangat diperlukan untuk mendeteksi anomali (outliers), mengevaluasi kualitas data, dan menentukan teknik pra-pemrosesan data yang paling tepat agar hasil data mining menjadi lebih akurat dan valid.

LANDASAN TEORI & PENJELASAN PROPERTI STATISTIK#

Deskripsi Data Statistik#

Untuk memahami karakteristik dari sekumpulan data secara mendalam, kita memerlukan deskripsi statistik dasar yang pada umumnya terbagi menjadi pengukuran tendensi sentral (central tendency) dan pengukuran tingkat penyebaran (dispersion) data. Melalui aplikasi KNIME Analytics Platform, proses ekstraksi statistik ini dapat dilakukan secara otomatis.
Berikut adalah penjelasan dari masing-masing properti statistik yang dihasilkan oleh aplikasi KNIME berdasarkan konsep dasar Data Understanding:

  • Column: Nama atribut (dimensi, fitur, atau variabel) berupa data field yang merepresentasikan suatu karakteristik dari objek data yang sedang dianalisis.

  • Min (Minimum): Nilai terendah atau paling kecil dari sebuah atribut dalam keseluruhan himpunan data (dataset), yang digunakan sebagai salah satu indikator sebaran data.

  • Mean (Rata-rata): Ukuran tendensi sentral komputasi aljabar (algebraic measure) yang dihitung dengan menjumlahkan seluruh nilai sampel kemudian dibagi dengan jumlah keseluruhan sampel data tersebut.

  • Median: Nilai tengah dari sebuah himpunan data untuk mengukur tendensi sentral; apabila jumlah datanya ganjil maka diambil nilai yang berada tepat di tengah (setelah diurutkan), dan jika genap maka dihitung rata-rata dari dua nilai di tengah.

  • Max (Maksimum): Nilai tertinggi atau paling besar dari sebuah atribut di dalam dataset.

  • Std. Dev. (Standar Deviasi): Akar kuadrat dari nilai varians, yang berfungsi untuk mengukur dan merepresentasikan tingkat penyebaran (dispersion) atau seberapa jauh nilai-nilai data menyimpang dari nilai ekspektasi (rata-rata).

  • Skewness: Ukuran kemiringan distribusi data, yang mendeteksi apakah suatu sebaran data bersifat simetris, condong ke arah kanan (positively skewed), atau condong ke arah kiri (negatively skewed).

  • Kurtosis: Ukuran yang menunjukkan tingkat keruncingan puncak kurva (atau penumpukan data di area ekor distribusi) dari sebuah himpunan data jika dibandingkan dengan kurva distribusi normal.

  • No. Missing: Jumlah baris atau sel data yang terdeteksi kosong (null) dan tidak memiliki nilai masukan.

  • No. \(+\infty\) (Unlimited Positif): Jumlah perhitungan atau rekaman nilai yang merepresentasikan tak terhingga yang bernilai positif.

  • No. \(-\infty\) (Unlimited Negatif): Jumlah perhitungan atau rekaman nilai yang merepresentasikan tak terhingga yang bernilai negatif.

METODOLOGI#

Migrasi Data CSV ke Cloud Database (Aiven PostgreSQL)#

Tahapan awal pada praktikum ini adalah proses pemindahan (migrasi) data lokal berupa fail CSV yang berisi dataset kualitas udara ke dalam pangkalan data awan (cloud database). Layanan yang digunakan adalah PostgreSQL berbasis cloud yang disediakan oleh platform Aiven. Setelah pangkalan data berhasil dikonfigurasi dan URI (Uniform Resource Identifier) untuk koneksi diperoleh, pangkalan data tersebut diakses melalui antarmuka manajemen pgAdmin. Selanjutnya, sebuah tabel baru bernama tb_polutan_labang diinisiasi dengan struktur kolom yang telah disesuaikan. Data dari fail CSV kemudian diimpor ke dalam tabel tersebut sehingga pangkalan data dapat diakses secara terpusat melalui cloud.

  • Tampilan antarmuka pgAdmin yang menampilkan isi tabel tb_polutan_labang sebagai bukti keberhasilan migrasi data ke server Aiven.

Penarikan Data dari Cloud ke KNIME Analytics Platform#

Untuk keperluan penambangan data (data mining), data yang telah tersimpan di server Aiven diekstraksi ke dalam lingkungan kerja KNIME Analytics Platform. Proses integrasi dan ekstraksi ini mengimplementasikan tiga buah node utama yang dieksekusi secara sekuensial, yaitu:

  • PostgreSQL Connector: Node ini berfungsi untuk menginisiasi koneksi ke server pangkalan data Aiven. Konfigurasi dilakukan dengan memasukkan parameter kredensial yang meliputi hostname, nama basis data, username, password, serta penambahan pengaturan keamanan pada tab JDBC Parameters berupa nilai sslmode = require.

  • DB Table Selector: Node ini berfungsi untuk menyeleksi dan memilih tabel spesifik yang akan dianalisis, yaitu tabel tb_polutan_labang, dari skema pangkalan data yang telah terhubung.

  • DB Reader: Node ini mengeksekusi perintah SQL secara internal guna memuat seluruh hasil seleksi data ke dalam memori kerja (data table lokal) aplikasi KNIME.

Prapemrosesan Data dan Ekstraksi Properti Statistik#

Setelah data termuat ke dalam aplikasi KNIME, tahapan berikutnya adalah prapemrosesan data (data preprocessing). Pada observasi awal, ditemukan adanya nilai kosong (missing value) pada beberapa baris variabel observasi polutan. Penanganan nilai kosong tersebut dilakukan dengan mengimplementasikan node Missing Value. Konfigurasi pada node ini ditetapkan agar seluruh atribut bertipe numerik (Double/Float/Integer) yang kosong diimputasi secara otomatis menggunakan nilai rata-rata (Mean) dari masing-masing kolom. Setelah proses pembersihan data diselesaikan dan nilai kosong teratasi, tahapan dilanjutkan dengan analisis statistik deskriptif.

Proses ini dilakukan dengan menghubungkan keluaran (output) dari node Missing Value ke node Statistics. Node tersebut secara otomatis mengekstraksi dan menghitung berbagai metrik statistik dasar—seperti nilai minimum, maksimum, mean, varians, deviasi standar, serta skewness dan kurtosis—untuk memaparkan gambaran distribusi numerik dari masing-masing jenis gas polutan.

HASIL DAN PEMBAHASAN#

Hasil Tabel Statistik dari KNIME#

Setelah seluruh rangkaian alur kerja (workflow) dieksekusi secara sukses—mulai dari ekstraksi data dari cloud database Aiven PostgreSQL, penanganan nilai kosong (missing value) menggunakan metode imputasi rata-rata (mean), hingga pemrosesan data numerik—aplikasi KNIME Analytics Platform berhasil menghasilkan ringkasan karakteristik data secara komprehensif. Melalui penggunaan node Statistics, seluruh metrik deskriptif dasar dari setiap atribut polutan udara (seperti nilai minimum, maksimum, rata-rata, hingga deviasi standar) terangkum secara otomatis ke dalam bentuk tabel analitik yang terstruktur.

Contoh Perhitungan Manual Properti Statistik#

A. Perhitungan Mean (\(\mu\))

  • Rumus:$\(\mu = \frac{\sum x_i}{n}\)$

  • Proses Hitung: $\(\frac{0.025 + 0.030 + 0.028 + 0.025 + 0.032}{5} = \frac{0.140}{5}\)$

  • Hasil Akhir:$\(\text{Mean} = 0.028\)$

B. Perhitungan Median

  • Langkah Pengurutan Data (dari terkecil ke terbesar):$\(0.025, 0.025, 0.028, 0.030, 0.032\)$

  • Analisis Posisi: Karena jumlah data (\(n\)) = 5 (bilangan ganjil), maka nilai median diambil dari data yang berada tepat di posisi tengah (indeks ke-3).

  • Hasil Akhir:$\(\text{Median} = 0.028\)$

C. Perhitungan Nilai Minimum dan Maksimum

Berdasarkan himpunan data yang telah diurutkan sebelumnya, dapat ditentukan batas ekstrim data sebagai berikut:

  • Min (Nilai Terendah): \(0.025\)

  • Max (Nilai Tertinggi): \(0.032\)

D. Perhitungan Standar Deviasi (\(s\))

  • Konsep Dasar: Varians sampel (\(s^2\)) dihitung dengan menjumlahkan kuadrat selisih antara setiap nilai data terhadap nilai rata-rata, kemudian dibagi dengan jumlah sampel dikurangi satu (\(n-1\)). Standar deviasi (\(s\)) diperoleh dengan menarik akar kuadrat dari nilai varians tersebut.

  • Proses Perhitungan Varians (\(s^2\)):$\(s^2 = \frac{(0.025 - 0.028)^2 + (0.025 - 0.028)^2 + (0.028 - 0.028)^2 + (0.030 - 0.028)^2 + (0.032 - 0.028)^2}{5-1}\)$$\(s^2 = \frac{0.000009 + 0.000009 + 0 + 0.000004 + 0.000016}{4}\)$$\(s^2 = \frac{0.000038}{4} = 0.0000095\)$

  • Proses Perhitungan Standar Deviasi (\(s\)):$\(s = \sqrt{0.0000095}\)$Hasil

  • Akhir:$\(\text{Standar Deviasi } (s) = 0.00308\)$

PENUTUP#

Kesimpulan#

Berdasarkan serangkaian praktikum dan analisis data polutan udara yang telah dilaksanakan, dapat ditarik beberapa kesimpulan utama sebagai berikut:

  • Keberhasilan Migrasi Data: Dataset lokal dalam format CSV berhasil dipindahkan dan diintegrasikan ke dalam cloud database (Aiven PostgreSQL) secara utuh, aman, serta dapat diakses kembali secara terpusat melalui manajemen basis data.

  • Efisiensi KNIME Analytics Platform: KNIME terbukti sangat handal dan efisien dalam menjembatani koneksi ke peladen basis data di cloud serta memproses pembersihan data (missing value) hingga visualisasi secara visual tanpa memerlukan penulisan kode (coding) yang rumit.

  • Validitas Metrik Statistik: Node Statistics pada KNIME mampu melakukan perhitungan metrik tendensi sentral dan penyebaran data secara otomatis, yang terbukti selaras dan valid ketika diuji menggunakan logika perhitungan matematis manual.

  • Dokumentasi Portofolio: Seluruh tahapan alur kerja (workflow), hasil analisis, hingga lampiran teknis telah berhasil didokumentasikan secara sistematis untuk dipublikasikan ke dalam web statis sebagai portofolio praktikum.
